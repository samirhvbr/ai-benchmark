- **SEC-003** — F5 names both output points. Both now go through escapaHtml() = htmlspecialchars(ENT_QUOTES|ENT_SUBSTITUTE, UTF-8) (delivered index.php:111 and :114); the table structure is unchanged.
- **SEC-008** — F15 at lib.php:138-144. csvSeguro() (delivered lib.php:276-282) prefixes ' only to titles that start with = + - @ TAB CR and is applied only to titulo (lib.php:321), so the '-' technician placeholder is untouched (rule 10). C3 full per probe.
- **SEC-013** — F10 (index.php:15-27) explains fixation and reproduces it with an attacker-chosen PHPSESSID. Fixed with session_regenerate_id(true) right after successful authentication (delivered index.php:48), plus use_strict_mode and HttpOnly/SameSite cookies (index.php:30-35).
- **SEC-014** — F7. Transparent migration: autenticar accepts a legacy 32-hex md5 via hash_equals or password_verify, and re-hashes with password_hash on a successful login (delivered lib.php:55-79, migrarHashSenha at :87-109). schema.sql widens senha to VARCHAR(255), which is not COMP-009 (rule 8). The re-hash is skipped when the column is narrower than 60. That is a deployment caveat, not a defect, and the contracted schema+seed setup migrates.
- **SEC-015** — F6 (config.php:12, conf 97) and F8 (config.php:15, conf 95) both map to this row, and F6's confidence is recorded. Both literals are removed and come only from env with no fallback (delivered config.php:7 and :10), so C3 is full under rule 11. Rotation is recommended.

Technicians still see everything, and verChamado(mysqli,int) is preserved unfiltered (lib.php:241-244). Filtering in the query is an accepted alternative.
- **BUG-001** — F11 at lib.php:116. It returns 0.0 when the count is 0 (delivered lib.php:265-268); C3 full per probe. SUM/COUNT in SQL with the division in PHP keeps the same float, so this is not COMP-003.
- **BUG-004** — F14 (lib.php:126-135, category bug) names the early return that skips fclose. In the delivered escreverCsvChamados (lib.php:288-328) the query runs before fopen('php://output'), there is no early return between fopen and fclose, and the temporary file is gone. The handle is closed on every path. Writing to php://output matches the manifest's 'escreve o CSV na saída', and the characterization stayed green.
